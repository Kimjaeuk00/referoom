## 실패·미달 문항 분류 (측정된 것만)

| 문항 | 현상 | 원인 단서(로컬 검색, LLM 없음) |
|---|---|---|
| R09 | 라이브러리에 없는 논문을 묻는 거절 시험인데 **답을 지어냄**(환각) | 검색 1위 0.601, 5개 모두 `MIN_SCORE` 0.55 이상이라 점수 차단을 통과하고 LLM이 답했다. **지난 수집에서는 같은 문항이 거절됐다**: 같은 코드에서 결과가 달라지는 불안정 |
| V03 | 일반 질문, 답했지만 부정확 | 정답 핵심어 2개 중 0개가 검색 문단에 있다(검색이 표 값을 못 찾음). **지난 수집에서는 거절됐다**: 마찬가지로 불안정 |
| R17 | 부정확 | 핵심어 2개 중 1개만 검색 문단에 있다 |
| R05 | 부정확 | 핵심어 3개 중 2개 포함 |
| R07(math) | 부정확 | 핵심어 3개 중 2개 포함 |
| R19 | 부정확 | 핵심어 2개 모두 검색 문단에 있는데도 부정확 → 생성 쪽 문제로 보임 |
| VF01 | 검증 판정이 기대와 불일치 | 두 번의 수집에서 같다(재현됨). 알려진 판정 보수성 |
| R08 | 수식 문항에 검토 배지 없음 | 두 번의 수집에서 같다(재현됨) |

주의: 핵심어 포함 여부는 정규식으로 센 근사치이며 판정기의 판단과 같지 않다. 원인은 단서일 뿐 확정이 아니다.

## 개선 후보 (사용자가 하나를 고른다)

| 후보 | 근거 | 영향(이 부분집합) | 메모 |
|---|---|---|---|
| 1. 라이브러리에 없는 논문·개념(R09의 DoRA 등)을 물었을 때 답을 지어내는 것 막기 | R09 환각, 같은 코드에서 결과가 갈림 | 거절 시험 1/9 | 환각은 유일하게 "틀린 답을 자신 있게" 낸 사례. 단 표본 1건이라 몇 번 더 돌려 빈도를 먼저 재는 것이 좋다 |

| 3. 검색이 정답 문단을 못 가져오는 경우(V03·R17 등) | 핵심어가 검색 문단에 없음 | 부정확 5건 중 2~3건 | 비교 질문 근거 쏠림(메모의 진단 1)과 같은 계열일 수 있으나 이번 부분집합에는 비교 질문이 없어 확인 못 함 |
| 4. 수식 문항 검토 배지(R08) | 두 번 재현 | math 1/3 | 작은 수정일 가능성 |
