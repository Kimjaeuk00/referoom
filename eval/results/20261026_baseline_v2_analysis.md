## 후보 1 재현 시험 (정정본)

**정정:** 같은 날 먼저 기록한 "124번 중 0번이라 후보 1 보류"는 **잘못된 측정**이었다. 시험 스크립트가 `RAG_STORE=local`을 설정하지 않아 파이프라인이 가짜 저장소(stub, 근거가 한 문단뿐)를 썼다. 아래는 `RAG_STORE=local`(실제 색인, 팀 3)로 다시 한 결과다. 같은 파이프라인(`pipeline.run`)을 서버 없이 직접 돌렸고, 온도는 0.3이다.

| 시험 | 횟수 | 거절하지 않고 답함 |
|---|---|---|
| R09 반복 | 30 | **3 (10%)** — 2건은 LoRA 논문 내용을 대신 설명, 1건은 "DoRA는 …"이라고 이름을 바꿔 서술 |
| 나머지 거절 시험 16개(부분집합 밖 4개 포함) 각 3번 | 48 | 0 |
| 라이브러리에 없는 기법 이름을 묻는 임시 질문 12개 각 3번(저장소에는 넣지 않음) | 36 | **6** — QA-LoRA 3/3(QLoRA 내용을 대신 설명), BitFit 3/3(LoRA 논문이 비교 대상으로 설명하는 방법이라 근거 있는 답일 수 있음). 나머지 10개는 0 |

- 서버 수집(baseline_v2)에서 R09가 한 번 답한 것과 맞는다.
- 문제의 모양: 질문한 기법 이름(DoRA, QA-LoRA)이 라이브러리 논문 이름(LoRA, QLoRA)과 겹쳐서 검색은 점수(0.60 안팎)를 통과하고, 모델이 이웃 논문의 설명으로 대신 답한다. 나머지 거절 시험 16개는 이름이 겹치지 않아 점수 차단에서 걸러진다.
- 후보 1은 **실제로 존재하는 문제**다(R09 10%, QA-LoRA 3/3). 보류 근거는 없다.

## 후보 1 적용 결과 (프롬프트 규칙 한 줄)

`prompts.py` 규칙 1에 "질문에 나온 기법·논문·모델의 이름이 [근거]에 나오지 않으면, 이름이 비슷한 다른 방법의 설명으로 대신 답하거나 이름만 바꿔 쓰지 말고 found=false로 답한다"를 더했다. 같은 시험을 `RAG_STORE=local`로 다시 돌렸다(온도 0.3).

| 시험 | 전 | 후 |
|---|---|---|
| R09 거절하지 않고 답함 | 3/30 | **0/30** |
| 없는 기법 이름 임시 질문 12개 | 6/36 | **3/36** (QA-LoRA 3/3 → 0/3, 남은 것은 BitFit 3/3) |
| 답해야 하는 18문항의 거절(3회씩) | 예전 프롬프트 1/54 | **0/54** |

- BitFit은 LoRA 논문이 비교 대상으로 직접 설명하는 방법이라, 답이 근거에 있다. 환각으로 세지 않는다.
- 표본이 작다(R09 30회, 임시 질문 36회, 거절 18문항×3). 정식 전후 비교는 C4(36문항 + 판정기)에서 한다.
- 이 시험은 서버 없이 같은 파이프라인을 직접 돌린 것이다.
