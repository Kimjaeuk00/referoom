# PAGE_IMAGES 비용·지연 측정 (설정은 바꾸지 않음)

`PAGE_IMAGES`를 시험 스크립트에서만 껐다/켜서, 답할 수 있는 튜터 문항 32개를 각 1회 같은 파이프라인(`RAG_STORE=local`, 서버 없이 직접 실행)으로 돌렸다. 토큰은 파이프라인이 기록한 입력·출력 토큰(이미지 재시도 호출 포함)이고 금액은 단가를 몰라 계산하지 않았다(미측정).

## 구조 (코드 확인)

- 기본 답은 항상 텍스트 검색(RAG)이다. 이미지는 **재시도에만** 쓴다(`pipeline.run`의 이미지 재시도 분기).
- 재시도 조건(`retry_blocks`): 텍스트 답이 `found`이고, 답에 수치 모양(`\d+%`, 소수, `$`, 두 자리 이상 정수)이 있고, 답이 인용한 블록 중 표·그림·수식 표시(`visual`: 청크에 수식·표가 있거나 캡션)가 붙은 것이 있을 때. 조건이 안 맞으면 추가 호출이 없다.
- 이미지 상한: 질문당 최대 2페이지(`PAGE_IMAGE_MAX`), 이미지 모델은 `LLM_IMAGE_MODEL`로 따로 정할 수 있다.

## 결과 (32문항, 1회씩)

| | 끔(현재 기본) | 켬 |
|---|---|---|
| 평균 입력 토큰 | 1,802 | 3,114 (+73%) |
| 평균 출력 토큰 | 129 | 173 |
| 평균 지연 | 1.9초 | 2.6초 |
| 이미지 재시도가 일어난 문항 | 0 | **15/32 (47%)** |
| 핵심 수치가 든 답(정규식 근사) | 16/32 | 18/32 |
| 거절 | 0 | 0 |

- 재시도가 일어난 15개의 입력 토큰은 평균 1,911 → 4,708(약 2.5배), 지연은 1.5초 → 3.6초다. 재시도가 없는 문항은 차이가 없다.
- 켜서 달라진 것은 2문항(R07 수식, V03 표 값)이 핵심 수치를 갖게 된 것뿐이다. 나머지 13개는 재시도를 했지만 이 근사 기준으로는 결과가 같았다.
- 한계: 1회씩이라 흔들림이 있고, 정확성은 정규식 근사다(판정기 아님). 이 문항 구성(수식·표 문항이 많음)은 실제 사용 질문의 분포가 아니다(미측정).

## 정정과 추가 측정: 이미지 모델 3가지 구성 (같은 32문항, 1회씩)

위 표는 이미지 모델이 `gpt-4o`인 상태에서 잰 것이다. 이전 기록(`shrimp_data/progress_rag.md`, 2026-10-23)에는 권장 구성(텍스트 `gpt-4o` + 이미지 재시도 `gpt-6-luna`·추론 강도 `none`)이 이미 측정돼 있고 `rag-service/.env.examplerag`에 주석으로만 남아 있다. 실제 `.env`에는 없어서 서버 설정은 이미지 모델 `gpt-4o`, `PAGE_IMAGES=off`다. 같은 문항으로 세 구성을 다시 쟀다.

| 구성 | 평균 입력 토큰 | 평균 지연 | 이미지 재시도 | 핵심 수치 포함(정규식 근사) | 재시도 문항의 평균 입력·출력 토큰, 지연 |
|---|---|---|---|---|---|
| 끔 | 1,802 | 1.9초 | 0/32 | 13/32 | - |
| 켬, 이미지 `gpt-4o` | 3,135 | 2.7초 | 15/32 | 17/32 | 4,748 / 184, 3.7초 |
| 켬, 이미지 `gpt-6-luna`(`none`) | 4,199 | 3.1초 | 15/32 | 17/32 | 7,059 / 261, 4.6초 |

- 끔 설정의 핵심 수치 포함이 앞선 측정(16/32)과 이번(13/32)에서 3문항 다르다. 1회 측정의 흔들림이 이 정도이므로, 켬과 끔의 차이(+4)도 흔들림 범위를 크게 벗어나지 않는다.
- 두 이미지 모델의 정확도는 이 문항에서 같다(17/32). 이전 기록에서 `gpt-6-luna`가 앞선 근거는 V01(그래프의 막대·범례 판독)인데, V01은 현재 라이브러리에 없는 논문의 질문이라 `questions_parked`로 옮겨졌고 이번 문항에는 없다. 즉 그래프 판독 차이는 현재 라이브러리로 **다시 확인하지 못했다**.
- `gpt-6-luna`는 토큰이 더 많이 든다(재시도 문항 기준 입력 +49%). 이전 기록은 토큰 단가가 훨씬 낮아 질문당 비용이 낮다고 했지만(혼합 약 $0.0051 vs `gpt-4o` 단독 $0.0074) 그 단가는 2차 출처라 공식 확인 전이다. 이번 측정에서는 금액을 계산하지 않았다(미측정).
- 재시도 비율은 이번 문항에서 47%(15/32)로, 이전 기록의 일반 53문항 23%(12/53)보다 높다. 문항 구성(수식·표 질문이 많음)과 색인이 달라서다.
